# Визуализация конечноэлементного решения эллиптической краевой задачи

Приложение для расчета и трехмерной визуализации решения эллиптической краевой задачи методом конечных элементов (МКЭ). Дипломный проект на ФПМИ НГТУ.

## 🚀 Функционал:
- Расчет эллиптических краевых задач с использованием конечноэлементных сеток.
- Построение и 3D-визуализация расчетной сетки и полученного решения.
- Управление отображением (поворот, масштабирование, перемещение камеры).

## 💻 Стек технологий:
- **Язык:** C# (.NET Framework / .NET Core)
- **Интерфейс:** WinForms
- **3D-Графика:** SharpGL
